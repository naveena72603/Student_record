

Student Record Management System

A mini project developed in C using Singly Linked List to manage student records. The system supports adding, deleting, modifying, displaying, sorting, and saving student information.
Technologies Used

    C Programming
    Single Linked List(ds)
    File Handling
    Makefile
    GCC Compiler
    Linux

Features

    Add Record
    Delete Record
    Modify Record
    Display Records
    Sort Records
    Save Records to File

How to Complie

    using GCC : gcc*.c -o outfile (or)
    using makefile : make

How to Run

    ./Outfile
